## Software Engineering Profile

I am a fourth year Computer Science student at An Najah National University building toward a career in Software Engineering.

I enjoy understanding how a system works end to end, turning requirements into working features, and improving the structure behind the code rather than only making the interface look finished. My current focus is full stack development, data structures and algorithms, backend fundamentals, APIs, and practical AI integrations.

Across university projects and hackathons, I have worked with Java, JavaScript, TypeScript, React, Vue, Node.js, Express, SQL, REST APIs, Git, and AI APIs. I have also led technical delivery in team environments, which taught me how much clear communication matters when software has to move from an idea to a working demo.

I am currently looking for Software Engineering, Backend, and Full Stack internship opportunities where I can keep building stronger Software Engineering fundamentals through real work.

## Selected Software Engineering Projects

### [BookStoreDSA](https://github.com/yousefwalidabubaker/BookStoreDSA)

A Java bookstore system built to apply core data structures and Software Engineering principles to a practical workflow.

**What it demonstrates:**

- Custom hash table with separate chaining for ISBN lookup
- Binary search tree for ordered title indexing
- Generic linked queue for order processing
- Service-layer separation between business rules and data structures
- Input validation and edge-case protection
- Self-contained tests that run with the JDK alone

**Tech:** Java, custom data structures, CLI, testing

### [MIN HON](https://github.com/yousefwalidabubaker/MIN-HON)

A bilingual Palestinian heritage e-commerce prototype with product customization and an AI shopping assistant.

**Result:** 2nd Place, Innovate IT Hackathon AI Track  
**Role:** Technical Team Leader

**Software Engineering highlights:**

- React + TypeScript storefront
- Node.js + Express backend
- Shared validation and API schemas
- AI assistant integration through a server-side endpoint
- Monorepo structure with shared client, database, and integration packages

**Tech:** React, TypeScript, Vite, Node.js, Express, Drizzle ORM, Zod, OpenAI API

### [EWB Campus Expo](https://github.com/yousefwalidabubaker/EWB-An-Najah-Campus-Expo)

A responsive event website built for the EWB Campus Expo at An Najah National University.

**Software Engineering highlights:** searchable and filterable booth data, visitor and exhibitor flows, browser persistence, responsive pages, and GitHub Pages deployment.

**Tech:** HTML, CSS, JavaScript, Vue 3, Local Storage, GitHub Pages

### [Voice of the Market](https://github.com/yousefwalidabubaker/voice-of-the-market-ai)

An AI retail-availability system concept combining camera-based inventory monitoring with QR-based customer reports.

**Result:** Winner, Voice of the Market Challenge at AINAK Challenges 2026

The repository focuses on the system flow, architecture decisions, requirements, data signals, risks, and implementation considerations behind the hackathon solution.
